# Code of Conduct

This project adopts the [Contributor Covenant][cc], version 2.1, as its code
of conduct: be respectful, assume good faith, and keep discussion on the
technical work. Unacceptable behaviour includes personal attacks, harassment,
and publishing others' private information.

Instances may be reported privately to the maintainers through GitHub. All
complaints will be reviewed and handled confidentially. Maintainers may
remove comments, commits, code or contributors that do not follow it.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The full text is available at the link above; this file intentionally records
the commitment and the reporting route rather than duplicating it.
